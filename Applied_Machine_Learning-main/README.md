# Customer Clustering Dashboard

A Streamlit-based customer clustering dashboard for analyzing and segmenting **5,452 customers** based on financial and loan-related features.

The project compares six machine learning approaches and provides an interactive interface for exploring model performance, cluster distributions, customer profiles, and live customer cluster prediction.

---

## 📌 Project Overview

Customer segmentation can help financial institutions understand different customer profiles and identify groups with different financial and credit behavior.

This project applies multiple clustering and machine learning techniques to customer financial data and compares their performance using the **Silhouette Score** and other evaluation metrics.

The project also includes an interactive **Streamlit dashboard** that allows users to:

* Compare the performance of six models.
* Explore individual model results.
* Analyze cluster distributions.
* View customer cluster profiles.
* Enter new customer information.
* Predict the customer's cluster using the selected trained model.

---

## 🎯 Objectives

* Segment customers based on financial and loan behavior.

## Models

The project evaluates six approaches.

### 1. DEC — Deep Embedded Clustering

Deep Embedded Clustering uses an autoencoder to learn a lower-dimensional representation of the data before performing clustering.

* Latent dimension: **5**
* Pretraining epochs: **30**
* Fine-tuning epochs: **40**
* Reported Silhouette Score: **0.9779**
* Selected clustering configuration: **2 clusters**

DEC produced a strong separation between the main customer risk groups.

---

### 2. GMM + RBM

This approach combines a **Restricted Boltzmann Machine (RBM)** for representation learning with a **Gaussian Mixture Model (GMM)** for clustering.

* RBM hidden units: **15**
* GMM covariance type: **Full**
* GMM initialization: **10**
* Best number of components according to BIC search: **5**
* Reported Silhouette Score: **0.9941**

GMM + RBM achieved the highest reported Silhouette Score among the evaluated approaches.

---

### 3. SOM + KMeans

This approach uses a **Self-Organizing Map (SOM)** to map customer data into a lower-dimensional topology followed by KMeans clustering.

* SOM grid: **20 × 20**
* Number of neurons: **400**
* Optimal number of clusters: **3**
* Silhouette Score: **0.7794**
* Quantization Error (QE): **1.1969**
* Topographic Error (TE): **0.1922**

---

### 4. KMeans

KMeans was applied directly to the scaled customer features.

* Best k: **2**
* `n_init`: **20**
* Silhouette Score: **0.7709**

The resulting clusters were highly imbalanced, with approximately **93.2%** of customers in the main cluster and **6.8%** in the secondary cluster.

---

### 5. SVM — RBF Kernel

SVM was used as a supervised model to learn and predict cluster labels generated from the SOM-based approach.

* Kernel: **RBF**
* Gamma: **0.001**
* C: **5.0**
* Class weight: **balanced**
* Test Accuracy: **99.82%**
* Silhouette Score: **0.7656**

> **Important:** SVM is not directly clustering the raw dataset. It learns to predict cluster labels generated by the SOM-based clustering process.

---

### 6. DBSCAN

DBSCAN was evaluated as a density-based clustering method using PCA representations and different epsilon values.

* Clusters found: **14**
* Silhouette Score: **0.0457**
* Noise points: **1,544**
* Noise percentage: **28.3%**
* PCA components: **7**
* Fallback epsilon: **0.738**

DBSCAN performed poorly on this dataset because of its low Silhouette Score and high percentage of noise points.

##  Model Comparison

| Model            | Silhouette Score | Reported Clusters |
| ---------------- | ---------------: | ----------------: |
| **GMM + RBM**    |       **0.9941** |                 3 |
| **DEC**          |       **0.9779** |                 2 |
| **SOM + KMeans** |       **0.7794** |                 3 |
| **KMeans**       |       **0.7709** |                 2 |
| **SVM (RBF)**    |       **0.7656** |                 3 |
| **DBSCAN**       |       **0.0457** |                14 |

### Best Performing Models

* **GMM + RBM** achieved the highest reported Silhouette Score: **0.9941**.
* **DEC** achieved a strong Silhouette Score of **0.9779**.
* **SOM + KMeans** and **KMeans** provided reasonable clustering quality.
* **SVM** achieved **99.82% test accuracy** when predicting SOM-derived cluster labels.
* **DBSCAN** was not suitable for this dataset due to its low Silhouette Score and high noise percentage.

> **Note:** The number of clusters shown in the dashboard represents the selected/reporting configuration used by the application. Some model searches evaluated additional values of k or the number of mixture components.

## Live Customer Prediction

The dashboard allows users to enter information for a new customer, including:

* Age
* Employment type
* Bank
* Current loan amount
* Total due
* Loan term
* Interest rate
* Total amount returned
* Number of previous loans
* Previous loan amount
* Previous total due
* Previous loan term
* Days since the last loan

After entering the information, the user selects a clustering model and clicks **Predict cluster**.

When the required trained model files are available, the application uses the saved model for prediction.

If a required model file is unavailable or prediction fails, the application uses a **rule-based fallback** so that the dashboard can still return a result.

##  Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/project_AML.git
```

Move into the project directory:

```bash
cd project_AML
```

### 2. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit application

Because the application file is named `app1.py`, run:

```bash
streamlit run app1.py
```

The dashboard will then open in your browser.
